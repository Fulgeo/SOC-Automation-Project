# Setting Up TheHive

## Overview
This guide provides step-by-step instructions to set up **TheHive** on a **Google Cloud Virtual Machine (VM)**. TheHive is an open-source Security Incident Response Platform (SIRP) designed to manage and analyze security incidents.

## Virtual Machine Specifications
- **RAM**: 8GB+ (Recommended: 16GB)
- **HDD**: 50GB+
- **OS**: Ubuntu 22.04 LTS

## VM Setup
1. **Create a new VM** in Google Cloud Console.
2. **Select the following configurations**:
   - **Machine Type**: At least 8GB RAM (16GB recommended).
   - **Boot Disk**: Ubuntu 22.04 LTS with at least 50GB storage.
3. **Allow HTTP and HTTPS traffic**.
4. **Create the VM and connect to it** via SSH.

## Install Required Dependencies
Run the following command to install necessary dependencies:
```sh
sudo apt install wget gnupg apt-transport-https git ca-certificates ca-certificates-java curl software-properties-common python3-pip lsb-release
```

## Install Java
```sh
wget -qO- https://apt.corretto.aws/corretto.key | sudo gpg --dearmor -o /usr/share/keyrings/corretto.gpg
echo "deb [signed-by=/usr/share/keyrings/corretto.gpg] https://apt.corretto.aws stable main" | sudo tee -a /etc/apt/sources.list.d/corretto.sources.list
sudo apt update
sudo apt install java-common java-11-amazon-corretto-jdk
echo JAVA_HOME="/usr/lib/jvm/java-11-amazon-corretto" | sudo tee -a /etc/environment 
export JAVA_HOME="/usr/lib/jvm/java-11-amazon-corretto"
```

## Install Cassandra
```sh
wget -qO - https://downloads.apache.org/cassandra/KEYS | sudo gpg --dearmor -o /usr/share/keyrings/cassandra-archive.gpg
echo "deb [signed-by=/usr/share/keyrings/cassandra-archive.gpg] https://debian.cassandra.apache.org 40x main" | sudo tee -a /etc/apt/sources.list.d/cassandra.sources.list
sudo apt update
sudo apt install cassandra
```

### Configure Cassandra
1. Open the Cassandra configuration file:
   ```sh
   sudo nano /etc/cassandra/cassandra.yaml
   ```
2. Modify the following settings:
   - Change the **cluster name** to a desired value.
   - Set **listen_address**, **rpc_address**, and **seeds** (located in `seed_provider`) to your **TheHive VM's public IP address**.
3. Save the file and exit.
4. Stop Cassandra:
   ```sh
   sudo systemctl stop cassandra
   ```
5. Remove old Cassandra data (since TheHive was installed using a package):
   ```sh
   sudo rm -rf /var/lib/cassandra/*
   ```
6. Restart Cassandra:
   ```sh
   sudo systemctl start cassandra
   ```
7. Check Cassandra's status to ensure it is running correctly:
   ```sh
   sudo systemctl status cassandra
   ```

## Install Elasticsearch
```sh
wget -qO - https://artifacts.elastic.co/GPG-KEY-elasticsearch | sudo gpg --dearmor -o /usr/share/keyrings/elasticsearch-keyring.gpg
sudo apt-get install apt-transport-https
echo "deb [signed-by=/usr/share/keyrings/elasticsearch-keyring.gpg] https://artifacts.elastic.co/packages/7.x/apt stable main" | sudo tee /etc/apt/sources.list.d/elastic-7.x.list
sudo apt update
sudo apt install elasticsearch
```

### Configure Elasticsearch
1. Open the Elasticsearch configuration file:
   ```sh
   sudo nano /etc/elasticsearch/elasticsearch.yml
   ```
2. Modify the following settings:
   - Change the **cluster.name** to `thehive`.
   - Uncomment `node.name` and set it as `node-1`.
   - Uncomment `network.host` and set it to your **TheHive VM's public IP address**.
   - Uncomment `http.port` and ensure it remains `9200`.
   - Uncomment `cluster.initial_master_nodes` and remove `node-2` (since we don't have a second node).
3. Save the file and exit.
4. Start and enable Elasticsearch:
   ```sh
   sudo systemctl start elasticsearch
   sudo systemctl enable elasticsearch
   ```

### Configure TheHive
1. Check the ownership of `/opt/thp`:
   ```sh
   ls -la /opt/thp
   ```
   - If the files are owned by `root`, change ownership to `thehive`:
     ```sh
     sudo chown -R thehive:thehive /opt/thp
     ```
   - Verify the change:
     ```sh
     ls -la /opt/thp
     ```
2. Open the TheHive configuration file:
   ```sh
   sudo nano /etc/thehive/application.conf
   ```
3. Modify the following settings:
   - Change the **Cassandra hostname** to your **VM's public IP address**.
   - Ensure the **cluster name** matches what was set in the Cassandra configuration file.
   - Change the **Elasticsearch hostname** to your **VM's public IP address**.
   - Set `application.base.url` to your **VM's public IP address**.
4. Save the file and exit.
5. Start and enable TheHive:
   ```sh
   sudo systemctl start thehive
   sudo systemctl enable thehive
   ```

## Accessing TheHive
- TheHive runs on **port 9000**.
- Default credentials:
  - **Username**: `admin@thehive.local`
  - **Password**: `secret`
- Open a browser and navigate to:
  ```
  http://<your-vm-public-ip>:9000
  ```
