# Setting Up Sysmon

## Overview
This guide provides step-by-step instructions on setting up **Sysmon** for Windows endpoint monitoring. **Sysmon** (System Monitor) is a Windows system service and device driver that logs system activity to the Windows Event Log, which can be used for security monitoring and analysis.

## Download Sysmon and Configuration File

1. Download **Sysmon** from the official Microsoft Sysinternals website:
   - [Sysmon Download](https://learn.microsoft.com/en-us/sysinternals/downloads/sysmon)

2. Download a pre-configured **Sysmon Configuration File**:
   - [Sysmon Config](https://github.com/olafhartong/sysmon-modular/blob/master/sysmonconfig.xml)

## Installation Steps

### 1. Extract the Sysmon Installer
- After downloading, extract the Sysmon ZIP file to a directory of your choice.

### 2. Place the Configuration File
- Move the downloaded `sysmonconfig.xml` file into the **same directory** where the Sysmon installer (`Sysmon64.exe`) is located.

### 3. Open PowerShell as Administrator
- Press `Win + X`, then click **Windows Terminal (Admin)** or **PowerShell (Admin)**.

### 4. Change to the Sysmon Directory
Run the following command, replacing `<Sysmon_Directory>` with the actual path where Sysmon is extracted:
```powershell
cd "C:\path\to\Sysmon_Directory"
```

### 5. Install Sysmon
Run the following command to install Sysmon:
```powershell
.\Sysmon64.exe
```

### 6. Configure Sysmon
Execute the following command to apply the Sysmon configuration file:
```powershell
.\Sysmon64.exe -i sysmonconfig.xml
```
**Note:** Ensure that the file names in the command match the actual files saved on your computer.

### 7. Verify Sysmon Installation
To check if Sysmon is running properly, run:
```powershell
Get-Service -Name Sysmon64
```
If Sysmon is installed correctly, it should show **Running** status.
